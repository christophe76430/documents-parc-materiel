Ajout du code commun 131273 pour ouvrir le profil salarié sélectionné, en complément du code personnel existant basé sur la date d’anniversaire. Le code commun donne accès à tous les profils actifs de l’espace salariés ; il ne modifie pas le mot de passe administrateur.
