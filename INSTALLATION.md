# THN — installation V53

Cette version comprend :
- suppression complète de la recherche de logement chauffeur et de sa dépendance STAYINGAPI ;
- demande obligatoire du code chauffeur à chaque accès à « Espace » depuis l'accueil ;
- possibilité pour l'administration de modifier le code secret de chaque chauffeur ;
- conservation des documents chauffeurs et de l'authentification par session pour ouvrir leurs documents ;
- conservation des fonctions précédentes du parc, documents, échéances, extincteurs, ON/OFF et export.

## Installation
1. Décompresser cette archive.
2. Remplacer le contenu de la branche `nouvelle-version-thn` avec GitHub Desktop.
3. Commit puis Push.
4. Ne pas fusionner avec `main` avant validation.
