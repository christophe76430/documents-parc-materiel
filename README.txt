PARC MATÉRIEL — modèle gratuit

Ce dossier contient un site web statique prêt à être hébergé gratuitement.
23 fiches ont été préparées d'après la photo fournie : 13 pelles et 10 remorques.

Important :
- Les noms de conducteurs ne sont pas affichés.
- Les mentions « Document à ajouter » sont des emplacements.
- Avant diffusion, il faut remplacer ces emplacements par les vrais PDF/liens.
- Pour des documents sensibles, privilégier un stockage avec accès contrôlé plutôt qu'un PDF public.

Pour mettre le site en ligne gratuitement :
1. Créer un compte GitHub.
2. Créer un dépôt public, par exemple « parc-materiel ».
3. Envoyer le contenu du dossier « site » dans le dépôt.
4. Activer GitHub Pages dans Settings > Pages.
5. Une fois l'adresse du site connue, les QR codes définitifs peuvent être générés à partir des 23 adresses.
