Location avec chauffeur — sélection par défaut des documents à transmettre.

Chauffeur :
- CACES cochés par défaut ;
- pièce d'identité cochée par défaut ;
- permis de conduire cochés par défaut ;
- autorisation de conduite cochée par défaut.

Pelles :
- VGP cochée par défaut ;
- Agrément cochée par défaut ;
- Barre de shunt cochée par défaut.

Tous les autres documents sont décochés par défaut. Les cases restent librement modifiables avant la création du dossier client.
