THN V57

Modification : gestion du prochain rendez-vous de visite médicale des salariés.
- L'administrateur peut saisir ou modifier la date du prochain RDV pour chaque salarié/chauffeur.
- La date est enregistrée avec la fiche du salarié.
- Elle apparaît dans le tableau « Échéances » de l'espace salarié concerné uniquement.
- Elle n'apparaît pas dans le tableau général des échéances de l'accueil ni dans les pages publiques du parc.
- Le statut est calculé automatiquement : À jour, Dans X jours, ou En retard.

Base : V56.
